# Клавіатура не підключається / не заходить у прошивку — шпаргалка (macOS)

Довідка для DIY-клавіатур (QMK/ZMK). Два класи проблем: **дротова по USB-C**
(не бачиться як клавіатура / не заходить у бутлоадер) і **бездротова по
Bluetooth** (видно в списку, «Connect» мовчить).

Симптом-маркер обох: **попап на пів секунди і зникає**. Для USB це Keyboard
Setup Assistant (Mac побачив нову клаву й одразу її втратив). Для диска
бутлоадера — том змонтувався і відпав. У обох випадках пристрій **підключається
і за мить відпадає**.

---

## A. Дротова (USB-C)

### 1. Подивись, що Mac бачить
```bash
# Повний список USB-пристроїв
system_profiler SPUSBDataType

# Тільки твоя клава + її дескриптор
ioreg -p IOUSB -l -w0 | grep -iA25 -E "corne|crosses|keyboard|RP2|nice|foostan"

# Чи є HID-клавіатура на рівні драйвера
hidutil list | grep -i <ім'я>
```

**Як читати:**
- `IOServiceGetMatchingService did not return anything for location ...` —
  пристрій **був і зник під час сканування** = миготить (reset-петля).
- У дескрипторі `!matched` + **нема дочірнього `IOUSBHostInterface`** = Mac
  прочитав «паспорт» пристрою, але той **не підняв інтерфейс клавіатури**.
  Друкувати нема чим.
- `"USB Product Name"` / `"USB Vendor Name"` (напр. `foostan`) = працює
  **прошивка**, а не бутлоадер.

### 2. Який чип (визначає формат прошивки)
```bash
ioreg -p IOUSB -l -w0 | grep -iA25 <ім'я> | grep bMaxPacketSize0
```
- `bMaxPacketSize0 = 8`  → зазвичай **ATmega32U4 (AVR)** = «Arduino Pro Micro».
  Прошивка — **`.hex`**, бутлоадер — **послідовний порт**.
- `bMaxPacketSize0 = 64` → зазвичай **RP2040**. Прошивка — **`.uf2`**,
  бутлоадер — **диск `RPI-RP2`**.

### 3. Побач миготіння на власні очі
```bash
for i in $(seq 1 10); do ioreg -p IOUSB | grep -i <ім'я> || echo "— нема —"; sleep 0.5; done
```
- `<ім'я>` присутній усі рази = стабільно. `то є / то нема` = миготить.

### 4. Вирішальний тест: ROM-бутлоадер (залізо чи прошивка)
Бутлоадер живе в ROM чипа і не залежить від прошивки.
**Введи його: подвійний швидкий тап по reset** (або утримай `BOOT`/`BOOTSEL` +
раз reset).

```bash
# RP2040 — має змонтуватись диск
ls /Volumes                       # шукай RPI-RP2

# AVR — має зʼявитись серійний порт на ~8 секунд
ls /dev/cu.usbmodem* /dev/tty.usbmodem* 2>/dev/null
```
- **Бутлоадер зʼявляється чисто** → залізо й USB-шлях справні, **винна
  прошивка** → перепрошити (п.5).
- **Бутлоадер теж миготить / не зʼявляється** → **залізо**: кабель, гніздо
  USB-C (холодна пайка), або просадка живлення від RGB. Спробуй інший
  дата-кабель напряму в Mac, другу половину, поворуши штекер під кутом.

### 5. Залити прошивку
**RP2040 (.uf2)** — просто перетягнути:
```bash
cp ~/шлях/firmware.uf2 /Volumes/RPI-RP2/     # або drag-and-drop у Finder
```
**AVR (.hex)** — диском не монтується, треба **QMK Toolbox**:
1. Постав QMK Toolbox (додаток для Mac).
2. `Open` → вибери `.hex`, галка **Auto-Flash**.
3. Подвійний reset → плата стане Arduino-портом на ~8с → Toolbox заллє сам.

CLI-варіант для AVR (без Toolbox):
```bash
ls /dev/cu.usbmodem*              # знайди порт одразу після reset
avrdude -p atmega32u4 -c avr109 -P /dev/cu.usbmodemXXXX -U flash:w:firmware.hex
```

**Де взяти `.hex`/`.uf2`, якщо свого нема** — config.qmk.fm:
KEYBOARD (напр. `crkbd/rev1`) → KEYMAP `default` → **Compile** → **Download Firmware**.

**Спліт:** кожну половину флешать **окремо** тим самим файлом.

### 6. Швидкі засоби відновлення
- Застрягла прошивка (стабільний `!matched`, не друкує) — часто лікує
  **подвійний reset**: перезапускає прошивку чисто, USB переенумерується.
- Коли піднялась — у Keyboard Setup Assistant натисни клавішу біля лівого й
  правого Shift (або закрий / обери ANSI).

## B. Бездротова (Bluetooth)

Симптом: клава **в списку є**, а «Connect» нічого не робить. Майже завжди —
**застаріла пара** або **профіль уже заручений з іншим хостом**.

### 1. Що Mac реально бачить
```bash
system_profiler SPBluetoothDataType | grep -iA8 <ім'я>
```

### 2. Прибрати старий бонд на Mac
- System Settings → Bluetooth → наведи на пристрій → **ⓧ / Forget / Remove**.
- Вимкни Bluetooth і ввімкни; або скинь демон:
```bash
sudo pkill bluetoothd                 # сам підніметься
```

### 3. Очистити бонд на боці клавіатури (ZMK / nice!nano)
ZMK тримає **5 BLE-профілів**. Якщо вибраний заручений з іншим хостом — клава
рекламується, але до Mac не чіпляється.
- Переведи в режим пари (окреме комбо, не просто ввімкнути).
- Візьми **вільний профіль** і очисти старий бонд:
  - `&bt BT_SEL <n>` — перемкнути на профіль n;
  - `&bt BT_CLR` — очистити бонд поточного профілю.
- Перевір заряд.

## Шпаргалка команд

| Мета | Команда |
|---|---|
| Усі USB-пристрої | `system_profiler SPUSBDataType` |
| Дескриптор клави | `ioreg -p IOUSB -l -w0 \| grep -iA25 <ім'я>` |
| HID-клавіатури | `hidutil list` |
| Ловити миготіння | `for i in $(seq 1 10); do ioreg -p IOUSB \| grep -i <ім'я> \|\| echo "—"; sleep 0.5; done` |
| Диск бутлоадера (RP2040) | `ls /Volumes` → `RPI-RP2` |
| Порт бутлоадера (AVR) | `ls /dev/cu.usbmodem*` |
| Залити .uf2 | `cp fw.uf2 /Volumes/RPI-RP2/` |
| Залити .hex | QMK Toolbox, або `avrdude -p atmega32u4 -c avr109 -P <порт> -U flash:w:fw.hex` |
| Bluetooth-пристрої | `system_profiler SPBluetoothDataType` |
| Скинути Bluetooth | `sudo pkill bluetoothd` |

## Швидка діагностика

| Бачиш | Висновок | Дія |
|---|---|---|
| Попап на 0.5с, зникає | Пристрій підключається й відпадає | Кабель/гніздо/живлення; або подвійний reset |
| `!matched`, нема інтерфейсу | Прошивка не підняла HID | Подвійний reset; не допомогло — перепрошити |
| `did not return ... location` | Миготить у reset-петлі | Залізо: кабель, пайка USB-C, RGB-просадка |
| `RPI-RP2` у `/Volumes` | RP2040 у бутлоадері, залізо ОК | Перетягни `.uf2` |
| `cu.usbmodem*` на ~8с | AVR у бутлоадері, залізо ОК | QMK Toolbox з `.hex` |
| BLE в списку, Connect мовчить | Застаріла пара / зайнятий профіль | Forget на Mac + `BT_CLR` на клаві |
